# Carrossel Educativo — "Por que [Produto]?"

**Formato:** 5 slides | **Objetivo:** Educação de produto, construção de autoridade técnica
**Produto de referência:** [[Brand/technical-sheets/magnific-whey-chocolate-avela|Magnific Whey 3W]] ("Por que 3W?")

### Estrutura dos slides

```
SLIDE 1 — HOOK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Layout: Produto centralizado + texto grande + fundo textura
Texto principal: "PORQUE [PALAVRA-CHAVE] ??"
  - "PORQUE" → Montserrat Bold, azul escuro
  - [PALAVRA-CHAVE] → xBall Italic, dourado
  - "??" → vermelho, destaque de energia
Fundo: palavra-chave do produto repetida em cinza claro (efeito tipográfico)
Bandas diagonais: azul esquerda | vermelho direita

SLIDES 2, 3, 4 — TÉCNICOS (1 atributo por slide)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Layout: Produto em close ou ação (splash/efeito) + caixa de texto
Caixa de texto: fundo azul escuro semi-transparente
  - Tipo/atributo: branco + keyword em dourado → "[TIPO]:"
  - Descrição: branco Bold All-Caps, 2–3 linhas
Logo MP: canto inferior (alternado entre slides)
Bandas diagonais mantidas

Estrutura de copy por slide:
  Slide 2 → Atributo de VELOCIDADE/ABSORÇÃO
  Slide 3 → Atributo de COMPOSIÇÃO/PUREZA
  Slide 4 → Atributo de COMPLETUDE/AMPLITUDE

SLIDE 5 — CTA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Layout: Ambos os sabores/versões side-by-side + texto de ação
"SAIBA MAIS" → Montserrat ExtraBold, azul escuro, tamanho máximo
URL/CTA secundário → xBall Italic, dourado (ex: MPOFICIAL.COM)
Logo MP: canto superior esquerdo
Hero shot: produto principal em maior escala à direita
```

### Regras visuais do template

| Elemento | Especificação |
|----------|--------------|
| Bandas de cor | Azul `#20388a` diagonal esquerda + Vermelho `#d20a11` diagonal direita |
| Fundo textura | Palavra-chave do produto repetida, peso leve, cinza claro |
| Caixas de copy | Azul escuro semi-transparente, sem borda |
| Keyword destaque | Dourado (gradient) — apenas o tipo/nome do atributo |
| Copy técnico | Branco, Bold, All-Caps, máximo 3 linhas |
| Logo | Ícone branco MP, canto inferior ou superior alternado |
| Produto | Sem fundo (cut-out), com splash ou efeito de produto em ação |
